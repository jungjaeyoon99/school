개인정보 처리방침

1. 수집 목적
OL Banking 서비스의 로그인 확인, 서비스 이용 기록 관리 및 보안 유지를 위해 필요한 최소한의 정보를 수집합니다.

2. 수집 항목
Firebase Authentication 계정의 UID 및 이메일(이름), IP, 접속 시각, User-Agent를 수집할 수 있습니다.

3. IP 주소 확인에 관한 안내
접속 IP 확인을 위해 외부 서비스인 api.ipify.org를 이용할 수 있습니다. api.ipify.org에는 IP 주소 확인 요청이 전달될 수 있으며, 이는 접속 IP를 확인하기 위한 목적으로만 사용합니다.

4. 보유 및 폐기 기간
수집된 서비스 이용 및 보안 로그는 해당 학기 동안 보관하며, 보관 기간이 종료된 후 폐기합니다.

5. 제3자 제공
수집된 개인정보는 서비스 운영 및 보안 관리 목적 외의 용도로 사용하지 않으며 제3자에게 제공하지 않습니다.
단, 접속 IP 확인을 위해 api.ipify.org를 이용하는 과정에서 IP 주소가 해당 서비스로 전달될 수 있습니다.

6. 비밀번호
비밀번호는 OL Banking의 Realtime Database에 저장하지 않습니다. Firebase Authentication에서 관리하며, 비밀번호 변경 기록에도 실제 비밀번호는 저장하지 않습니다.

🔑 비밀번호 변경

보안을 위해 현재 비밀번호를 확인한 후 새 비밀번호로 변경합니다.
